# Maureen Wiart · Data Analyst portfolio

I turn data into decisions: analyses, reporting and dashboards that help managers act, and process
improvements backed by numbers. Six years in insurance, banking and audit, now applying SQL, Python,
R, Power BI and Excel to real business questions.

🌐 **Website:** [`index.html`](index.html) (published with GitHub Pages)

## Projects

Each project starts from a decision someone has to make and ends with a recommendation and its impact.

| Project | Tools | Result |
|---|---|---|
| [Journal entry testing: from 4,466 entries to five decisions](projects/journal-entry-testing/) | SQL, Python | 30/30 planted anomalies caught, review workload −99% |
| [Management reporting: sales on budget, margin is not](projects/sales-dashboard-powerbi/) | Power BI, DAX | €457k margin gap explained, 4 decisions, live web version |

## About this repository

- `index.html` and `assets/`: the website (plain HTML, CSS and JavaScript, no build step, no tracking).
- `projects/<name>/`: one folder per project, with its case-study page (`index.html`), a `README.md`,
  the code, the data and the results. Each project can be rerun from its README.

All data is synthetic, except the public DVF property records (Etalab / DGFiP, Licence Ouverte 2.0).
No client or employer data is used.
